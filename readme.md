# 🏥 Clinic Management System

A complete web-based Clinic Management System developed using PHP and MySQL. The system helps clinics manage doctors, patients, appointments, prescriptions, medicines, billing, and reports through a modern dashboard interface.

# Installation

1. Download the project.

2. Copy the project folder into your web server directory.

Example:

```
xampp/htdocs/
```

3. Open phpMyAdmin.

4. Create a new database.

Example:

```
clinic_management_system
```

5. Import the SQL database file.

6. Open

```
config/database.php
```

Update database credentials if needed.

```
$host = "localhost";
$username = "root";
$password = "";
$dbname = "clinic_management_system";
```

7. Start Apache and MySQL.

8. Open your browser.

```
http://localhost/project-folder/
```
